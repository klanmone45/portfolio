Авито Доставка

ЗАДАЧИ / 02

Зона ответственности

  • Разрабатывал визуальные решения для партнёрских ПВЗ и digital-коммуникаций Авито Доставки
  • Создавал шаблоны, навигационные материалы и инструменты для самостоятельного использования владельцами пунктов.

TOOLKIT / 03

Toolkit для
владельцев ПВЗ

Презентация для владельцев партнёрских пунктов о развитии и продвижении ПВЗ

Презентация имела 40 слайдов с практическим руководством о том, как пункту стать заметнее. Вместе с презентацией подготовил 200+ готовых материалов для социальных сетей, печати и локальных активностей, которые партнёры могли брать и использовать самостоятельно.

NAVIGATION / 04

Продвижение и навигация

Дополнительная система материалов для навигации к пунктам

Мы разработали систему материалов, которая помогала сделать ПВЗ заметнее в городе и привести пользователя непосредственно к пункту.

Я подготовил концепцию и бриф для подрядчика, курировал разработку и проводил дизайн-ревью материалов — от небольших indoor-форматов до крупной наружной рекламы.

ВХОДНАЯ ГРУППА / 05

Оформление
партнёрских ПВЗ

Наклейки для входной группы

Для входных групп партнёрских пунктов были разработаны брендированные наклейки Авито Доставки. Для части ПВЗ они стали одним из ключевых физических элементов присутствия бренда на точке.

Также я разработал шаблоны графика работы для фирменных лайтбоксов: продумал композицию, размеры, способ размещения и подготовил производственные макеты.

5POST / 06

Партнёрская
интеграция с 5Post

Оформление постамата

В рамках партнёрства с 5Post пользователи получили возможность заказывать товары с Авито в постаматы партнёра.

Я разработал оформление выделенных блоков постаматной колонны и адаптировал фирменную графику Авито под физический носитель.

Motion для постаматов

Для экранов 5Post подготовили отдельный motion-ролик об Авито Доставке.
